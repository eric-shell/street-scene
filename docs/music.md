# Music

The game has one persistent music player. It keeps playing across the menu, garage, races and drone mode, and remembers track, position, volume and shuffle between visits. Every track is credited in the player, in the "Now playing" banner, in the music library and on the credits screen with its **title, artist, album, source and license**.

## Library layout

One folder per artist and one per album:

```
assets/music/<artist-slug>/<album-slug>/album.json     credits and track list (you write this)
public/music/<artist-slug>/<album-slug>/NN-<track>.mp3  web audio (generated by npm run music)
src/assets/musicCatalog.json                           what the game reads (generated)
```

## Adding an artist or album

1. Only use music whose license allows it in a game, and record exactly what the license requires. CC BY requires title, author, source and license.
2. Create `assets/music/<artist-slug>/<album-slug>/album.json`, copying the 1000 Handz one as a template. Fill in `artist`, `artistUrl`, `album`, `albumShort`, `albumUrl`, `source`, `sourceUrl`, `license`, `licenseUrl`, and `tracks` (`number`, `title`, and the track page `url`).
3. Put the downloaded files in any folder. Each file name must start with its track number, e.g. `01 Artist - Title.mp3`.
4. Import:

   ```bash
   npm run music -- --album assets/music/<artist-slug>/<album-slug> --source "~/Downloads/<folder>"
   ```

   This transcodes every track with ffmpeg to 128 kbps MP3, normalizes loudness (EBU R128, -16 LUFS) so tracks play at a similar volume, writes the credit into the file's tags, and regenerates `src/assets/musicCatalog.json`. Files that are already up to date are skipped. Running `npm run music` with no arguments only rebuilds the catalog.
5. Run `npm test`. The music test checks every track has its file and full attribution.

Nothing else changes: the player, library and credits read the catalog.

## Controls

The player card sits bottom-right in the menu, garage and drone mode. Use the minimize button to shrink it to a pill; phones start minimized. During a race it collapses to a "now playing" chip, and a banner with full credit appears whenever the track changes.

| Key | Action |
|---|---|
| M | Mute or unmute music |
| ] | Next track |
| [ | Previous track (restarts the track if more than 4 s in) |

The music volume is also in Settings. OS media keys and lock screen controls work through the Media Session API. Browsers block audio until the first click or key press, so music starts then.
