# Blender for car work

Every session in the repo has the Blender tools, deferred: load the ones you need with ToolSearch (`select:mcp__blender__execute_blender_code,mcp__blender__look`, plus the `blender-lab` doc search) before the first call. If none are listed, run `.claude/skills/blender/mcp.sh status`; `register` adds them back, and they appear after a Claude Code restart.

**Model edits go through the Blender MCP.** Any change to a mesh, a `.blend` or a donor import (reshaping, rebuilding openings, recolouring faces, kits, a re-import) is done live through the `blender` MCP server, so the user sees it in their Blender and a Sketchfab donor can be imported again when the shipped mesh is too reduced to repair. If the session has no `blender` MCP tools (not even deferred), stop before editing, run `.claude/skills/blender/mcp.sh status` (`register` if it reports them missing) and ask the user to restart Claude Code; do not fall back to `blender -b` scripts. Headless stays only for what the pipeline runs itself (`saveCar.py`, `npm run assets`) and for read-only checks (renders, measurements) of shipped files. A worker given modelling work must run in an MCP session too, and only one agent drives the live scene at a time.

Authored cars are `assets/source/eshell/<carId>/<carId>.blend` (collections `Car`, `Parts`, `Wheels`, `Rig`; the contract is the docstring of `scripts/blender/exportCar.py` and README "Car assets"). `npm run assets` exports and catalogs them; you never export GLBs by hand for an authored car.

## Every MCP call

- Nothing persists between `execute_blender_code` calls. Start each call with
  `REPO='/Users/ericshell/Repositories/street-scene'; exec(open(REPO+'/scripts/blender/carKit.py').read())`
  and use its helpers (`imp`, `bake`, `bb`, `coll`, `show`, `cut`, `split_parts`, `islands`, `material_regions`, `plane_seam`, `seam_snap`, `arch_gap`, `remap_materials`, `copy_part`, `displace`, `recolor`, `outline`, `slab`, `fin`, `boundary_seam`, `surface_z`, `delete_islands`, `delete_faces`, `projected_quad` (axis `x`, `y` or `z` from above), `project_polygon`, `box`, `tube`, `surface_tree`, `mount_on_body`, `cam`, `preview`, `shading`). Add new helpers there, not inline.
- Reference work and the shared features: also `exec` `scripts/blender/carRefs.py` (`load_refs`, `measure`, `spec_check`, `spec_from_refs`, `ortho_sheet`, `tint_materials`) and `scripts/blender/carFeatures.py` (`apply_features`, `pillars`, `mirrors`, `handles`, `cowl`, `interior`, `lamps`, `exhaust`). The process is `/car`, the numbers `docs/carDesign.md`, the data `scripts/blender/carSpecs.json`.
- Blender space: meters, Z up, car faces **-Y**, +X is the car's left, origin on the ground between the axles. glTF car space is `(x, z, -y)` of that.
- Print numbers, look rarely: a `look` image costs far more than a printed bounds line. Use `max_size` 900 to 1100.
- `look(mode='angles')` auto frames every visible object; to judge a seam or a stance, `cam(target, direction, dist, lens)` then `look(mode='camera')`. Hide what you are not judging with `show([...])` or `preview(groups)`.
- The PreToolUse hook `.claude/hooks/check-blender-code.sh` blocks the calls below; do not work around it.

## Known traps (each cost a session)

| Trap | What happens | Do instead |
|---|---|---|
| `bpy.data.libraries.write(path, {scene})` | Crashes Blender 5.2, the user's session is gone | `bpy.ops.wm.save_as_mainfile(filepath=..., copy=True)` for a working copy, then `blender -b work.blend --python scripts/blender/saveCar.py -- <carId> <out.blend>` |
| `wm.open_mainfile`, `read_factory_settings` in the live session | Replaces the user's scene, can stop the MCP server | Headless `blender -b file.blend --python script.py` |
| `mesh.materials.clear()` | Every face's `material_index` becomes 0, the export is all Paint | `remap_materials(o)` |
| Meshopt GLBs from `public/` | Import fine, but the quantization sits in the node scale; overwriting `o.scale` shrinks or blows up the mesh | `imp()` bakes transforms on import; after that, transform with `bake(o, Matrix...)` only |
| `o.bound_box` after `mesh.transform()` | Stale until the depsgraph updates | `bb(o)` (vertex based) |
| Setting `o.location` for a side by side view, then `bake` | The offset is baked into the mesh | Lay out with `preview()` (linked duplicates), keep sources at the origin |
| Saving while `show()`/`preview()` hid the car collections | Hidden objects cannot be selected, so a `use_selection` glTF export writes the wrong objects (giant wheels, 47 validation errors) | `exportCar.py` now unhides everything and checks the selection; still call `show()` before saving a working copy |
| Two cars appended into one session | Their materials become `Paint` and `Paint.001`; a mesh left on a suffixed one exports a name validation rejects | `remap_materials` on every mesh before saving; `saveCar.py` purges the orphans |
| A work object put in the `preview` collection | The next `preview()` call empties that collection and deletes it (the Cupra R lip vanished mid build) | Keep work objects in a collection of their own; `show([...])` can list both |
| Judging lamps, grilles or colours with `look` | `look` draws every material in one colour and lens covers opaque, so a black panel in front of a headlamp bowl cannot be seen | `ray_map([objs], x0, x1, z0, z1)` (carKit.py): one letter per material seen through the covers |
| bmesh edits on a donor body or anything cut from it | Its authored normals are dropped; the export reshades and every collapse sliver shows | `stash_normals(o)` before, `restore_normals(o)` after (`split_off`, `bumper_lip`, `patch_out` already do) |

## Recipes

- **Edit an authored car live**: append its collections without switching files: `with bpy.data.libraries.load(path, link=False) as (src, dst): dst.collections = list(src.collections)`, then link each to the scene (both cars can sit in one session). When done: `remap_materials`, `show()`, `bpy.ops.wm.save_as_mainfile(filepath=<scratch>/work.blend, copy=True)`, `saveCar.py` per car headless.
- **Load a shipped car**: `imp('public/cars/<id>.glb', '<id>')`, parts likewise.
- **Normalize scale**: every car rides on `standardWheel` (`scripts/assetConfig.json`, 0.28 m radius). Scale a body uniformly about the origin, then check `arch_gap(body, x, axle_y, 0.28)`: about 0.01 to 0.04 m is right; negative means the tire pokes through the lip (never shrink the wheel; raise the body or open the arch instead), large means drop the body with `bake(o, Matrix.Translation((0, 0, -dz)))`.
- **Split a merged body**: `material_regions(body)` and `islands(body)` to find the light lines and arches; `cut(body, planes)` with axis planes (front bumper: y < front arch edge and z < headlight bottom; rear likewise; skirts: |x| > sill, z < sill top, between the arches); `split_parts(body, ...)`. Kitbashed IceMaan meshes have about 100 islands that cross part lines, so plane cuts beat island picking.
- **New aftermarket parts**: build them from the stock piece, never from another kit (kit 1 / kit 3 donors seam snapped onto the kit 2 body looked wrong and were dropped). `copy_part(stock, '<carId>.<slot>_<partId>', '<carId>:Parts')`, then `displace(o, fn, plane_seam(...))` (moves fade to zero at the seam, so the fit stays exact), `recolor(o, pred, 'Trim')` for carbon or body colour panels, and new geometry with `outline` + `slab` (splitters, diffuser plates, skirt blades) and `fin` (canards, strakes, end plates). Pin new pieces to the part's own lowest point and silhouette; a plate under the lowest vertex of a rear bumper floats when the rear face sits higher. Keep strakes clear of the `Chrome` exhaust tips. `scripts/blender/tunerKits.py` (the Kurogane and Hayate kits) is the worked example to start from; displacements of 2 to 6 cm and plates of 2 to 10 cm read at game distance, 1 cm does not.
- **Panels cut by selection** (hood, roof): `cut` at the panel lines, `split_parts` with a box predicate (the Trim stripe and contrast roof outlined them), recolor the stock piece to Paint. Options pin to the panel's own edge with `boundary_seam(stock)`; place add-ons on the surface with `surface_z(o)(x, y)` (louvres, cowl slots, vortex generators, roof scoops). A new slot needs `PART_SLOTS`, `BODY_PART_SLOTS`, `SLOT_LABELS`, `TRI_BUDGETS` (`src/shared/parts.ts`), a share code key in `src/garage/storage.ts` and a `DEFAULT_HIDES` entry in `exportCar.py`.
- **Tame stock**: lips, splitters, strakes and integrated spoilers are their own islands; `delete_islands` them (on every roof or hood piece too when they straddle one), shrink grilles by cutting at |x| = 0.2 and recoloring the outer intake to Paint, close a bumper bottom with a black slab at the bottom edge of its *outer face* tucked 6 cm in (its lowest vertex sits further in, and a plate there floats). Stock is plain on purpose; character goes into parts.
- **Lights and grilles**: lamps come from `lamps(cid, m, 'front' | 'rear')` (carFeatures.py), which builds the car's signature from the spec at the house offsets and strips the old ones; by hand, `projected_quad(o, quad_uv, 'y', +1 front / -1 rear, offset, mat, target=[body, hood, bumper])` lays a patch on the surface; a black housing at 4 mm plus a lens at 12 to 14 mm reads as a framed lamp (less offset and the housing shows through on sloped spots). Keep the lens off the hood's front edge (rays jump to the hood top; `max_jump` drops those cells). Side wraps project along x. Recolor the old light faces to Paint first. Round lamps are fans of tiny quads.
- **Reshaping a whole car** (flares): one displacement field applied to every mesh in `Car` and `Parts` keeps every seam closed; move the Rig wheels out with it.
- **Compare with references**: `load_refs(cid)` puts the calibrated photos of `assets/refs/<cid>/refs.json` behind the car as textured planes (`<cid>:Refs`); `ortho_sheet(cid, out_dir)` renders side / front / rear / top with temporary wheels (and the planes, `xray=True` to see through the car) to PNGs you Read; `spec_check(cid)` prints the audit table live. In the live session a render may open Blender's render window; harmless.
- **Spoilers**: always `mount_on_body(sp, [Body, Roof, Hood, Bumper_Rear], dys)`; pass only the dy range you want (roof edge for hatches, trunk lid for the others) or it picks the nearest valid spot, which can block the rear glass.
- **A new car from scratch**: `scripts/blender/kazamaRotor.py` lofts a body from mirrored rings over stations (every dimension is a keyframed profile), boolean cuts the arches (the cutter's inside becomes the black wheel well; `material_mode='TRANSFER'`), adds lights, grilles, mirrors, handles, exhaust and an Interior block (glass is 70 % opaque). Then the usual: cut and `split_parts` into `Body`, bumpers, `Skirts`, `Hood`, `Roof`; add its SEAMS to `tunerKits.py` and run the kit, hood and roof builders; spoilers; Rig empties. Outside Blender: a manifest entry (displayName, engine, defaultPaint, `selectable`, a universal `defaultWheel` if it has no wheels of its own), a `cars.<id>` block in `drivingParams.json` (measure with `/tune`), and the tests that list the garage cars (`tests/sim.test.ts`, `tests/carSpec.test.ts`).
- **Names**: parts are named after fictional tuners (`frontBumper_kurogane`, displayName `Kurogane`; spoilers and wheels too, via the `displayName` property), never Street/Sport/Pro or numbers: no visual hierarchy. Check a new name is not a real tuner brand.
- **Restyle on the mesh**: chop a roof by compressing z above the belt line (`z = belt + (z - belt) * k`, apply the same to roof spoilers); repaint panels by bisecting at panel lines with `cut` and setting `material_index` per face center (hood stripe |x| < 0.40 Trim, roof |x| < 0.52 Trim, B-pillar faces (|x| > 0.45, 0.18 < y < 0.36, outward normals) Black on the Wendt Strom, after the Proto Compact).
- **Assemble and save**: build `<carId>:Car|Parts|Wheels|Rig` collections in the working file (object names may carry a `<carId>.` prefix; the exporter strips it), `remap_materials` on every mesh, Rig empties at `(±x, ±axle_y, 0.28)`, `Parts` in garage order with a `displayName` property. Save a copy, run `saveCar.py` headless, then `npm run assets` (ask first; it rewrites generated catalog entries).
- **Verify the shipped result** without a browser: a headless render of `public/` GLBs (car plus parts plus wheels scaled to the manifest radius; the meshopt node scale must be dropped before scaling wheels). The game itself: `/dev` garage.

## Donor imports (cars and wheels)

The processes are `docs/carDonors.md` (`carDonors.py`: `donor`, `reduce_donor`) and `docs/carWheels.md` (`carWheels.py`: `wheel`, `wheel_report`, `wheel_sheet`). What they share, learned the hard way on 2026-10-21/22, applies to any model brought in from Sketchfab:

- **Licence first**, through the API (`https://api.sketchfab.com/v3/models/<uid>`: `license`, `isDownloadable`), then `import_asset(source='sketchfab', id=uid, target_size=...)`; the size is irrelevant, the pipeline scales from the wheelbase or the lip.
- **Names mean nothing.** Materials and objects are `Material.026` and `Object_12`; classify by geometry (radius bands, thickness, island count, position against the axles) and by keyword only as a first guess. Match names without the `.001` suffix a second import adds.
- **Weld first** (`remove_doubles`): models arrive shattered into thousands of islands, and a collapse refuses to touch open borders.
- **Reduce per kind, each to its own budget.** An error-driven collapse eats the small things first (mirrors, handles, spokes); a part that must survive is split off and collapsed alone: the cabin on a car, face / ring / cap on a wheel. Keep the budget where it shows: a face at 6,000, a shell at 16,000, a cabin at 2,500. Budgets are `BUDGET` / `INTERIOR_BUDGET` and `BUDGETS` in the two scripts, `TRI_BUDGETS` in `src/shared/parts.ts`.
- **A surface of revolution is turned, never collapsed**: a lip or barrel collapsed at any budget crumples; its visible profile (after the cull) lathed at 56 segments is clean and cheap (`_ring_profile`, `_lathe`).
- **Hardware is rebuilt, not reduced**: half a million triangles of bolts become hex heads at the bolts' own count, radius and depth (`_bolt_circles`, `_hex_heads`); hubs, nuts and calipers inside the tires' cylinders are deleted by position.
- **Cull hidden faces against the whole assembly** (tire or glass in place; glass transparent to the rays), from the directions the game sees, then take the shading skin **after** the cull: the cull rights faces modelled inside out and their authored normals with them.
- **A mirror reverses winding.** After any negative-determinant transform, `reverse_faces` so winding and authored normals agree, or the cull and the shading turn the model inside out.
- **Check with backface culling on** (`space.shading.show_backface_culling = True` on the viewport before a `look`): Blender draws both sides, the game draws `Rim` and `Tire` single sided. Print the count of faces pointing toward the viewer against away as the number.
- **The front cannot be read from the ring.** A deep dish and a deep barrel look the same to geometry; use the hub's badge, then look, then the recipe's `face`.
- **Lamps always mirror**: the +x lamps are reduced and copied across (`mirrorLamps`, on by default), so a recipe's lamp rules need only be right on one side.
- **Check in the game**: a garage shot through `.claude/skills/dev/shot.mjs` shows facets Blender's viewport hides; bodies keep the source's normals at export (`authored_normals`).
- **Lamps are layers, and only the big ones glow**: covers `Lens`, indicators `Light`, red reflectors `Reflector`, the third brake light `BrakeLight`, and `HeadLight` / `TailLight` only for the elements that light (a reflector, a bulb, a tail lamp's own lens). Decide from a photo of the real car; list the pieces with `lamp_islands`; the lamps are reduced apart and held while the shell collapses; a small round lamp becomes a `discs` entry, a fussy strip a `strips` one (`docs/carDonors.md`, Lamps).
- **Never ship a hand edit**: a reimport drops it. `edit_diff(cid, '<edited copy>')` turns the user's edits into recipe rules (`islands`, `cull`, `patches`); `ship_donor(cid, work)` ships the rebuilt `.Low` (docs/carDonors.md, Hand edits go in the recipe, Ship).
- **Compare against the source on a sheet** (`wheel_sheet`, `compare_donors`), front and three-quarter, solid and material; fidelity to the model the user picked is the measure, house replacements are for what the licence or the budget forbids (badges, tires, bolts).

## Blender

`/Applications/Blender.app/Contents/MacOS/Blender` (5.2); `npm run assets` also honors `BLENDER`.

Two MCP servers in `.claude/skills/blender/mcp.json`, each paired with a Blender add-on at the same pinned version:

- `blender` (MCP for Blender, port 9876): `execute_blender_code`, `look`, asset search and import. Everything in this skill goes through it, and the crash hook screens it.
- `blender-lab` (Blender Lab's official server, port 9877): `search_api_docs`, `get_python_api_docs`, `search_manual_docs` before guessing a `bpy` call or enum. Never write scene code through its `execute_blender_code`; the hook does not screen it.

A call that cannot connect: run `.claude/skills/blender/mcp.sh` (status) and follow what it prints. Setup, upgrades (`mcp.sh upgrade`), the Sketchfab switch and the traps are in [mcp.md](mcp.md); read it before changing either server or add-on.
