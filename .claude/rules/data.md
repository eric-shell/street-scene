# JSON data files

- `drivingParams.json`: `base` + `cars.<id>` absolute overrides (objects merge, arrays replace), `_` keys are comments, unknown keys or types throw at startup. Validate headless with `npx tsx .claude/hooks/check-tuning.ts`, measure with `npx tsx .claude/skills/tune/measure.ts`.
- `partsCatalog.json`: entries with `"generated": true` are rewritten by `npm run assets`; hand-written ones must pass `npm run validate`.
- `carManifest.json`: geometry in car space measured by the pipeline; `selectable` controls the garage list.
- `musicCatalog.json` is generated by `npm run music` from `assets/music/**/album.json`; edit the album files, not the catalog.
- Plain JSON (no comments, no trailing commas), 2-space indentation like the file.
